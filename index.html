Sobre Mim

Meu nome é Anderson Capato

Sou formado em Sistemas de Informação e atuo como Analista Financeiro com foco em FP&A e Dados, unindo planejamento financeiro a ferramentas técnicas como SQL, Python e APIs para resolver problemas que uma planilha sozinha não explica.

Antes disso, passei 12 anos no Bradesco como Gerente de Relacionamento e Investimentos, gerindo carteiras de clientes de alta renda e ampliando o volume sob gestão em 20%. Essa vivência me deu uma leitura de negócio que aplico hoje na análise financeira.

Meu diferencial é não parar na superfície do dado: quando um relatório não fecha, vou até a fonte — seja um ERP, uma API ou o XML de uma nota fiscal — para encontrar a causa raiz, não só o sintoma.

Busco oportunidades como Analista Financeiro (FP&A) ou Analista de Dados Financeiro, unindo essas duas frentes para melhorar a tomada de decisão da empresa através de dados.

Investigação de divergência de frete entre VTEX, Softvar e transportadora via API

Identifiquei, via consumo direto da API da VTEX e análise do XML da NFe, a causa raiz de uma cobrança indevida de frete pela transportadora Total Express — um erro de conversão de peso no motor de faturamento do Softvar, que VTEX, ERP e a transportadora não conseguiam explicar. A descoberta, sustentada por evidência técnica reproduzível, expôs uma perda estimada de R$108 mil por ano e direcionou a correção ao fornecedor certo.

R$ 1,3 milhão parados no estoque: cruzamento de três fontes de dados
